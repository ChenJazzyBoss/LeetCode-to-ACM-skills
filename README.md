# LeetCode-to-ACM Skills 🎯

> Claude Code Skill — 扮演 ACM 竞赛的裁判 + 教练，帮你从 LeetCode 格式过渡到 ACM 格式。

## 项目定位

```
你（选手）                    Skill（裁判 + 教练）
   │                                │
   │  ── 给题号 ────────────────→  │ 抓取力扣原题，转成 ACM 格式题面
   │                                │
   │  ←── 题目 + 测试用例 ────────  │
   │                                │
   │  ── 提交代码 ──────────────→  │ 逐用例运行，对比输出，打分
   │                                │
   │  ←── 判题报告 + 修复建议 ──→  │ AC/WA/RE/TLE + 错误定位
   │                                │
```

## 核心功能

| # | 功能 | 命令 | 说明 |
|---|------|------|------|
| 1 | 抓取原题 | `/acm fetch <题号>` | 从力扣获取题目，转成 ACM 格式 |
| 2 | Hot 100 训练 | `/acm hot100` | 按分类/随机出题，跟踪训练进度 |
| 3 | 生成测试用例 | `/acm test <题号>` | 自动构造多组用例（输入 + 预期输出） |
| 4 | 代码评判 | `/acm judge` | 运行代码，逐用例对比，判定 AC/WA |
| 5 | 打分 | 内置于 judge | 通过用例数/总用例数 × 100 |

## 与 LeetCode 的区别

```
┌──────────────┬──────────────────┬────────────────────┐
│              │  LeetCode        │  ACM               │
├──────────────┼──────────────────┼────────────────────┤
│ 输入方式     │  函数参数        │  stdin / input()   │
│ 输出方式     │  return 值       │  stdout / print()  │
│ 代码结构     │  class Solution  │  直接写顶层代码     │
│ 多组测试     │  不需要处理      │  需要循环处理多组   │
│ 评判方式     │  平台自动跑      │  echo 管道 + 对比   │
└──────────────┴──────────────────┴────────────────────┘
```

## 评判机制

### 打分规则

```
用例 #1 [基础]     ──→  AC ✅   20分
用例 #2 [边界-n=1] ──→  AC ✅   20分
用例 #3 [全相同]   ──→  WA ❌    0分
用例 #4 [递增]     ──→  AC ✅   20分
用例 #5 [随机]     ──→  AC ✅   20分

总分：80 / 100    通过率：4/5
```

### 判定类型

| 判定 | 含义 | 触发条件 |
|------|------|----------|
| 🟢 AC | 正确 | 输出完全匹配 |
| 🟡 WA | 答案错误 | 输出不匹配 |
| 🔴 RE | 运行错误 | 抛出异常 |
| 🟠 TLE | 超时 | 运行时间过长 |
| ⚪ CE | 编译错误 | 语法错误 |

### 评判方式

```bash
echo "5
1 2 3 4 5" | python solution.py
```

管道输入 → 捕获输出 → 与预期对比 → 逐用例打分
