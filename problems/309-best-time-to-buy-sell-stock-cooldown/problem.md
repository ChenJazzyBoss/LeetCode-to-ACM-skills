# 309. 最佳买卖股票时机含冷冻期

**难度**：Medium
**知识点**：动态规划、数组
**输入模式**：basic

## 题目描述

给定一个整数数组 `prices`，其中 `prices[i]` 表示第 `i` 天的股票价格。你可以完成多次交易，但卖出股票后第二天无法买入（冷冻期一天）。求最大利润。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出最大利润。

## 样例

**输入：**
```
5
1 2 3 0 2
```

**输出：**
```
3
```

## 数据范围

- 1 ≤ n ≤ 5000
- 0 ≤ prices[i] ≤ 1000
