# 75. 颜色分类

**难度**：Medium
**知识点**：双指针、排序、数组
**输入模式**：basic

## 题目描述

给定一个包含红色、白色、蓝色（共 `n` 个元素）的数组 `nums`，原地对其进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。这里用整数 `0`、`1`、`2` 分别表示红色、白色和蓝色。本题以输出排序后的数组即可。

## 输入格式

第一行输入一个整数 `n`。
第二行输入 `n` 个整数（取值为 0、1、2）。

## 输出格式

输出排序后的 `n` 个整数，空格分隔。

## 样例

**输入：**
```
6
2 0 2 1 1 0
```

**输出：**
```
0 0 1 1 2 2
```

## 数据范围

- 1 ≤ n ≤ 300
- nums[i] ∈ {0, 1, 2}
