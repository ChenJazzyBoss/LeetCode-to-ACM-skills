# 238. 除自身以外数组的乘积

**难度**：Medium
**知识点**：数组、前缀和
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。题目保证数组中任意元素的全部前缀元素和后缀的乘积都在 32 位整数范围内。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出 `n` 个整数，空格分隔。

## 样例

**输入：**
```
4
1 2 3 4
```

**输出：**
```
24 12 8 6
```

## 数据范围

- 2 ≤ n ≤ 10⁵
- -30 ≤ nums[i] ≤ 30
