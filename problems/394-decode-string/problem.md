# 394. 字符串解码

**难度**：Medium
**知识点**：栈、字符串、递归
**输入模式**：basic

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。编码规则为 `k[encoded_string]`，表示 `encoded_string` 重复 `k` 次。`k` 保证为正整数。输入的方括号总是格式正确的。

## 输入格式

第一行输入编码字符串 `s`。

## 输出格式

输出解码后的字符串。

## 样例

**输入：**
```
3[a]2[bc]
```

**输出：**
```
aaabcbc
```

## 数据范围

- 1 ≤ len(s) ≤ 30
