# 128. 最长连续序列

**难度**：Medium
**知识点**：哈希表、数组
**输入模式**：basic

## 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。要求时间复杂度 O(n)。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个整数，表示数组。

## 输出格式

输出一个整数，表示最长连续序列的长度。

## 样例

**输入：**
```
6
100 4 200 1 3 2
```

**输出：**
```
4
```

## 数据范围

- 0 ≤ n ≤ 10⁵
- -10⁹ ≤ nums[i] ≤ 10⁹
