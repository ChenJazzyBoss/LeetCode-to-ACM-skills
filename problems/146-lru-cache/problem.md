# 146. LRU 缓存

**难度**：Medium
**知识点**：哈希表、链表、设计
**输入模式**：basic

## 题目描述

请你设计并实现一个满足 LRU（最近最少使用）缓存约束的数据结构，支持 `put` 和 `get` 操作。`get(key)`：若关键字存在于缓存中，返回其值并标记为最近使用；否则返回 `-1`。`put(key, value)`：若关键字已存在，更新其值并标记为最近使用；否则插入该关键字值对。当容量达到上限时，应在写入前逐出最久未使用的关键字。

## 输入格式

第一行输入一个整数 `capacity`，表示缓存容量。
第二行输入一个整数 `q`，表示操作次数。
接下来 `q` 行，每行一个操作，格式为：
- `GET key`
- `PUT key value`

## 输出格式

按顺序输出每个 `GET` 操作的返回值，每行一个。

## 样例

**输入：**
```
2
6
PUT 1 1
PUT 2 2
GET 1
PUT 3 3
GET 2
GET 3
```

**输出：**
```
1
-1
3
```

## 数据范围

- 1 ≤ capacity ≤ 3000
- 0 ≤ key, value ≤ 10⁴
- 1 ≤ q ≤ 10⁴
