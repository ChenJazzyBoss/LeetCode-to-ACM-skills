# 322. 零钱兑换

**难度**：Medium
**知识点**：动态规划、BFS、数组
**输入模式**：basic

## 题目描述

给你一个整数数组 `coins`，表示不同面额的硬币；以及一个整数 `amount` 表示总金额。计算并返回可以凑成总金额所需的最少硬币个数。如果没有任何硬币组合能凑成，返回 `-1`。

## 输入格式

第一行输入 `n`，表示硬币种类数。
第二行输入 `n` 个整数，表示各面额。
第三行输入 `amount`。

## 输出格式

输出最少硬币数，无法凑成输出 `-1`。

## 样例

**输入：**
```
3
1 2 5
11
```

**输出：**
```
3
```

## 数据范围

- 1 ≤ n ≤ 12
- 1 ≤ coins[i] ≤ 2³¹ - 1
- 0 ≤ amount ≤ 10⁴
