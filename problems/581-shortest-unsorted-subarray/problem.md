# 581. 最短无序连续子数组

**难度**：Medium
**知识点**：数组、排序、双指针
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums`，你需要找出一个连续子数组，如果对这个子数组进行升序排序，那么整个数组都会变为升序排序。请你找出符合题意的最短子数组，并输出它的长度。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出最短子数组的长度。

## 样例

**输入：**
```
5
2 6 4 8 10
```

**输出：**
```
2
```

## 数据范围

- 1 ≤ n ≤ 10⁴
- -10⁵ ≤ nums[i] ≤ 10⁵
