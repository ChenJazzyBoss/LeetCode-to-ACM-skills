# 347. 前 K 个高频元素

**难度**：Medium
**知识点**：堆、哈希表、排序
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你返回其中出现频率前 `k` 高的元素。可以按任意顺序返回。

## 输入格式

第一行输入 `n k`。
第二行输入 `n` 个整数。

## 输出格式

输出前 `k` 个高频元素，升序排列，空格分隔。

## 样例

**输入：**
```
6 2
1 1 1 2 2 3
```

**输出：**
```
1 2
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 1 ≤ k ≤ 不同元素个数
