# 10. 正则表达式匹配

**难度**：Hard
**知识点**：动态规划、字符串
**输入模式**：basic

## 题目描述

给定一个字符串 `s` 和一个字符模式 `p`，实现支持 `.` 和 `*` 的正则表达式匹配。`.` 匹配任意单个字符，`*` 匹配零个或多个前面的元素。匹配应该覆盖整个字符串。

## 输入格式

第一行输入字符串 `s`。
第二行输入模式串 `p`。

## 输出格式

输出 `true` 或 `false`。

## 样例

**输入：**
```
aa
a*
```

**输出：**
```
true
```

## 数据范围

- 1 ≤ |s| ≤ 20
- 1 ≤ |p| ≤ 30
- s 仅包含小写英文字母
- p 包含小写英文字母、`.` 和 `*`
