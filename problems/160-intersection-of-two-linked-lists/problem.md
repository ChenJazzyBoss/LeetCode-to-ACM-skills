# 160. 相交链表

**难度**：Easy
**知识点**：链表、双指针
**输入模式**：basic

## 题目描述

给你两个单链表的头节点，请你找出并返回两个单链表相交的起始节点（的值）。如果两个链表不存在相交节点，返回 `-1`。本题以序列描述：分别给出链表 A、链表 B 的节点值序列，以及相交节点的值 `intersectVal`（`0` 表示不相交）。

## 输入格式

第一行输入若干整数，为链表 A 的节点值。
第二行输入若干整数，为链表 B 的节点值。
第三行输入一个整数 `intersectVal`，表示相交节点的值（`0` 表示不相交）。

## 输出格式

输出相交节点的值，不相交输出 `-1`。

## 样例

**输入：**
```
4 1 8 4 5
5 6 1 8 4 5
8
```

**输出：**
```
8
```

## 数据范围

- 0 ≤ 节点数 ≤ 3×10⁴
- 1 ≤ Node.val ≤ 10⁵
