# 494. 目标和

**难度**：Medium
**知识点**：动态规划、DFS、数组
**输入模式**：basic

## 题目描述

给你一个非负整数数组 `nums` 和一个整数 `target`。向数组中的每个整数前添加 `+` 或 `-`，然后串联起所有整数，构造一个表达式。返回可以通过上述方法构造的、运算结果等于 `target` 的不同表达式的数目。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个非负整数。
第三行输入 `target`。

## 输出格式

输出表达式数目。

## 样例

**输入：**
```
5
1 1 1 1 1
3
```

**输出：**
```
5
```

## 数据范围

- 1 ≤ n ≤ 20
- 0 ≤ nums[i] ≤ 1000
- 0 ≤ sum(nums[i]) ≤ 1000
- -1000 ≤ target ≤ 1000
