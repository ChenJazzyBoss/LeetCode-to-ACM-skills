# 72. 编辑距离

**难度**：Medium
**知识点**：动态规划、字符串
**输入模式**：basic

## 题目描述

给定两个字符串 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。你可以对一个单词进行以下三种操作：插入一个字符、删除一个字符、替换一个字符。

## 输入格式

第一行输入字符串 `word1`。
第二行输入字符串 `word2`。

## 输出格式

输出一个整数，表示最少操作数。

## 样例

**输入：**
```
horse
ros
```

**输出：**
```
3
```

## 数据范围

- 0 ≤ |word1|, |word2| ≤ 500
- word1 和 word2 由小写英文字母组成
