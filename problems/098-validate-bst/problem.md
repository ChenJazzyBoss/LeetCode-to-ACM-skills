# 98. 验证二叉搜索树

**难度**：Medium
**知识点**：二叉树、DFS、递归
**输入模式**：tree

## 题目描述

给定一棵二叉树，判断其是否是一个有效的二叉搜索树（BST）。BST 定义为：
- 左子树只包含小于当前节点的数
- 右子树只包含大于当前节点的数
- 所有左子树和右子树自身也是 BST

## 输入格式

第一行输入一个整数 `n`，表示节点数（节点值为 1 到 n）。
接下来 `n-1` 行，每行两个整数 `u v`，表示一条边（u 是 v 的父节点）。
根节点为 1。BST 中每个节点有一个值，第 i 个节点的值为 i。

## 输出格式

输出 `true` 或 `false`。

## 样例

**输入：**
```
2
1 2
```

**输出：**
```
true
```

## 数据范围

- 1 ≤ n ≤ 10⁴
