# 2. 两数相加

**难度**：Medium
**知识点**：链表、递归
**输入模式**：basic

## 题目描述

给定两个用链表表示的非负整数，每位数字都是逆序存储的，每个节点存储一位数字。将两个数相加，并以相同形式返回一个表示和的链表。

## 输入格式

第一行输入一个整数 `n`，表示第一个数的位数。
第二行输入 `n` 个数字（0-9），表示第一个数（逆序）。
第三行输入一个整数 `m`，表示第二个数的位数。
第四行输入 `m` 个数字（0-9），表示第二个数（逆序）。

## 输出格式

输出结果的各位数字（逆序），用空格分隔。

## 样例

**输入：**
```
3
2 4 3
3
5 6 4
```

**输出：**
```
7 0 8
```

## 数据范围

- 0 ≤ digits[i] ≤ 9
- 数字不含前导零（0 本身除外）
