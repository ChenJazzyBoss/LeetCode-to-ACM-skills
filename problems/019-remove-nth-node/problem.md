# 19. 删除链表的倒数第 N 个结点

**难度**：Medium
**知识点**：链表、双指针
**输入模式**：basic

## 题目描述

给定一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

## 输入格式

第一行输入 `k` 个整数，表示链表节点值（空格分隔）。
第二行输入一个整数 `n`，表示要删除的倒数位置。

## 输出格式

输出删除后的链表节点值，空格分隔。如果链表为空则输出空行。

## 样例

**输入：**
```
1 2 3 4 5
2
```

**输出：**
```
1 2 3 5
```

## 数据范围

- 1 ≤ k ≤ 30
- 1 ≤ n ≤ k
