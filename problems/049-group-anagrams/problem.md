# 49. 字母异位词分组

**难度**：Medium
**知识点**：哈希表、字符串、排序
**输入模式**：basic

## 题目描述

给定一个字符串数组，将字母异位词组合在一起。字母异位词是由相同字母重新排列形成的不同字符串。

## 输入格式

第一行输入一个整数 `n`，表示字符串数量。
第二行输入 `n` 个字符串，空格分隔。

## 输出格式

每组字母异位词输出一行，字符串用空格分隔，组内按字典序排列。所有组按第一词字典序输出。

## 样例

**输入：**
```
6
eat tea tan ate nat bat
```

**输出：**
```
ate eat tea
bat
nat tan
```

## 数据范围

- 1 ≤ n ≤ 10⁴
- 0 ≤ strs[i].length ≤ 100
- strs[i] 仅包含小写英文字母
