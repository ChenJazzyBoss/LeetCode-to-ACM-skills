# 207. 课程表

**难度**：Medium
**知识点**：图论、拓扑排序、BFS
**输入模式**：graph

## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1`。在选修某些课程之前需要一些先修课程。给你一个数组 `prerequisites`，其中 `prerequisites[i] = [a_i, b_i]`，表示如果要学习课程 `a_i` 则必须先学习课程 `b_i`。请你判断是否可能完成所有课程的学习。如果能，输出 `Yes`；否则输出 `No`。

## 输入格式

第一行输入两个整数 `n` 和 `m`，分别表示课程数量和先修条件数量。
接下来 `m` 行，每行输入两个整数 `a b`，表示课程 `a` 的先修课程为 `b`。

## 输出格式

输出 `Yes` 或 `No`。

## 样例

**输入：**
```
4 2
1 0
2 1
```

**输出：**
```
Yes
```

## 数据范围

- 1 ≤ n ≤ 2000
- 0 ≤ m ≤ 5000
- 0 ≤ a_i, b_i < n
