# 15. 三数之和

**难度**：Medium
**知识点**：双指针、数组、排序
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 0 且不重复的三元组。注意：答案中不可以包含重复的三元组。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个整数，表示数组 `nums`。

## 输出格式

输出所有满足条件的三元组，每行一个三元组，格式为 `a b c`（三个数用空格分隔），按字典序排列。

## 样例

**输入：**
```
6
-1 0 1 2 -1 -4
```

**输出：**
```
-1 -1 2
-1 0 1
```

## 数据范围

- 3 ≤ n ≤ 3000
- -10⁵ ≤ nums[i] ≤ 10⁵
