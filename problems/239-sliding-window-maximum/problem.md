# 239. 滑动窗口最大值

**难度**：Hard
**知识点**：队列、滑动窗口、单调队列
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums` 和一个滑动窗口大小 `k`，窗口从数组的最左侧滑动到最右侧，每次向右移动一位。返回每个窗口中的最大值。

## 输入格式

第一行输入两个整数 `n k`。
第二行输入 `n` 个整数。

## 输出格式

输出 `n-k+1` 个整数，空格分隔。

## 样例

**输入：**
```
8 3
1 3 -1 -3 5 3 6 7
```

**输出：**
```
3 3 5 5 6 7
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 1 ≤ k ≤ n
