# 25. K 个一组翻转链表

**难度**：Hard
**知识点**：链表、递归
**输入模式**：basic

## 题目描述

给定一个链表，每 `k` 个节点一组进行翻转，请返回翻转后的链表。如果节点总数不是 `k` 的整数倍，请将最后剩余的节点保持原有顺序。

## 输入格式

第一行输入链表节点值，空格分隔。
第二行输入一个整数 `k`。

## 输出格式

输出翻转后的链表节点值，空格分隔。

## 样例

**输入：**
```
1 2 3 4 5
2
```

**输出：**
```
2 1 4 3 5
```

## 数据范围

- 1 ≤ 链表长度 ≤ 5000
- 0 ≤ Node.val ≤ 1000
- 1 ≤ k ≤ 链表长度
