# 56. 合并区间

**难度**：Medium
**知识点**：排序、数组
**输入模式**：matrix

## 题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [start_i, end_i]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组。

## 输入格式

第一行输入一个整数 `n`，表示区间数量。
接下来 `n` 行，每行输入两个整数，表示一个区间的左右端点。

## 输出格式

输出合并后的区间，每行一个区间，格式为 `start end`，按左端点从小到大排列。

## 样例

**输入：**
```
4
1 3
2 6
8 10
15 18
```

**输出：**
```
1 6
8 10
15 18
```

## 数据范围

- 1 ≤ n ≤ 10⁴
- intervals[i].length == 2
- 0 ≤ start_i ≤ end_i ≤ 10⁴
