# 337. 打家劫舍 III

**难度**：Medium
**知识点**：二叉树、动态规划、DFS
**输入模式**：tree

## 题目描述

在上次打劫完一条街道之后，小偷发现了一个新的可行窃的地区，但这个地区的所有房子排列类似于一棵二叉树。如果两个直接相连的房子在同一天晚上被打劫，房屋将自动报警。给定二叉树的根节点，返回在不触动警报的情况下小偷能盗取的最高金额。

## 输入格式

第一行输入以空格分隔的层序序列，`null` 表示空节点，节点值为金额。

## 输出格式

输出最高金额。

## 样例

**输入：**
```
3 2 3 null 3 null 1
```

**输出：**
```
7
```

## 数据范围

- 节点数 ≤ 10⁴
- 0 ≤ Node.val ≤ 10⁴
