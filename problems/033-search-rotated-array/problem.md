# 33. 搜索旋转排序数组

**难度**：Medium
**知识点**：二分查找、数组
**输入模式**：basic

## 题目描述

给定一个升序排列的整数数组 `nums`，在某个未知的下标 `k` 处进行了旋转，使得数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`。给定一个目标值 `target`，如果 `target` 存在于数组中，返回其下标，否则返回 `-1`。

## 输入格式

第一行输入 `n` 个整数，表示旋转后的数组。
第二行输入一个整数 `target`。

## 输出格式

输出 `target` 在数组中的下标，不存在则输出 `-1`。

## 样例

**输入：**
```
4 5 6 7 0 1 2
0
```

**输出：**
```
4
```

## 数据范围

- 1 ≤ n ≤ 5000
- -10⁴ ≤ nums[i] ≤ 10⁴
- nums 中的每个值都唯一
- -10⁴ ≤ target ≤ 10⁴
