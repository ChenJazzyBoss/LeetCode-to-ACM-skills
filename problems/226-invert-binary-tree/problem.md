# 226. 翻转二叉树

**难度**：Easy
**知识点**：二叉树、DFS、BFS
**输入模式**：tree

## 题目描述

给你一棵二叉树的根节点，翻转这棵二叉树，并返回其层序遍历结果。输入描述：第一行为节点数 `n`，接下来 `n-1` 行每行 `p c side`（side 为 `L`/`R`）描述父子关系，根为 1。输出翻转后的层序遍历。

## 输入格式

第一行输入 `n`。
接下来 `n-1` 行，每行 `p c L/R`。

## 输出格式

输出翻转后二叉树的层序遍历，节点编号用空格分隔。

## 样例

**输入：**
```
3
1 2 L
1 3 R
```

**输出：**
```
1 3 2
```

## 数据范围

- 0 ≤ n ≤ 100
