# 236. 二叉树的最近公共祖先

**难度**：Medium
**知识点**：二叉树、DFS
**输入模式**：tree

## 题目描述

给定一棵二叉树，找到该树中两个指定节点的最近公共祖先（LCA）。输入：第一行为节点数 `n`，随后 `n-1` 行 `p c L/R` 描述父子关系，最后一行两个整数 `p q` 为待查节点编号。根为 1。

## 输入格式

第一行 `n`。
接下来 `n-1` 行，每行 `p c L/R`。
最后一行两个整数 `p q`。

## 输出格式

输出 LCA 节点的编号。

## 样例

**输入：**
```
7
1 2 L
1 3 R
2 4 L
2 5 R
3 6 L
3 7 R
4 7
```

**输出：**
```
1
```

## 数据范围

- 1 ≤ n ≤ 10⁴
