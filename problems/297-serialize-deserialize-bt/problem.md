# 297. 二叉树的序列化与反序列化

**难度**：Hard
**知识点**：二叉树、DFS、BFS、字符串
**输入模式**：tree

## 题目描述

序列化是将一个数据结构转化为比特位序列的过程，以便存储或传输。请实现二叉树的序列化与反序列化。本题输入一行以空格分隔的前序序列，用 `null` 表示空节点。要求将其反序列化为二叉树，再输出其层序遍历（空节点跳过）。

## 输入格式

第一行输入以空格分隔的前序序列，`null` 表示空节点。

## 输出格式

输出反序列化后二叉树的层序遍历（不含空节点），数值用空格分隔。

## 样例

**输入：**
```
1 2 null null 3 4 null null 5 null null
```

**输出：**
```
1 2 3 4 5
```

## 数据范围

- 节点数 ≤ 10⁴
- -1000 ≤ Node.val ≤ 1000
