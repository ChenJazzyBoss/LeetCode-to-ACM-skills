# 210. 课程表 II

**难度**：Medium
**知识点**：图论、拓扑排序、BFS
**输入模式**：graph

## 题目描述

现在你总共有 `n` 门课需要选，记为 `0` 到 `n-1`。给你一个先修关系，`a b` 表示学习 `a` 前需先学 `b`。请返回任意一种可以学完所有课程的排列顺序。如果不可能完成所有课程，输出空行。

## 输入格式

第一行输入两个整数 `n m`，分别表示课程数和先修条件数。
接下来 `m` 行，每行输入 `a b`。

## 输出格式

输出一种合法的学习顺序，节点用空格分隔。若存在环则输出空行。

## 样例

**输入：**
```
4 2
1 0
2 1
```

**输出：**
```
0 1 2 3
```

## 数据范围

- 1 ≤ n ≤ 2000
- 0 ≤ m ≤ 5000
