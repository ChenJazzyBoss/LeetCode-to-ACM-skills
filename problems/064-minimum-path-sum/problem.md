# 64. 最小路径和

**难度**：Medium
**知识点**：动态规划、矩阵
**输入模式**：matrix

## 题目描述

给定一个包含非负整数的 `m × n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和最小。每次只能向下或向右移动一步。

## 输入格式

第一行输入两个整数 `m` 和 `n`，表示网格行数和列数。
接下来 `m` 行，每行 `n` 个整数，表示网格。

## 输出格式

输出最小路径和。

## 样例

**输入：**
```
3 3
1 3 1
1 5 1
4 2 1
```

**输出：**
```
7
```

## 数据范围

- 1 ≤ m, n ≤ 200
- 0 ≤ grid[i][j] ≤ 100
