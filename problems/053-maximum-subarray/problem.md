# 53. 最大子数组和

**难度**：Medium
**知识点**：动态规划、数组
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个整数，表示数组 `nums`。

## 输出格式

输出一个整数，表示最大子数组和。

## 样例

**输入：**
```
9
-2 1 -3 4 -1 2 1 -5 4
```

**输出：**
```
6
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- -10⁴ ≤ nums[i] ≤ 10⁴
