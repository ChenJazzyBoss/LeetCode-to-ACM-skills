# 406. 根据身高重建队列

**难度**：Medium
**知识点**：贪心算法、排序、数组
**输入模式**：matrix

## 题目描述

假设有打乱顺序的一群人站成一个队列，数组 `people` 表示队列中一些人的属性，每个元素 `people[i] = [h_i, k_i]` 表示第 `i` 个人的身高为 `h_i`，前面正好有 `k_i` 个身高大于或等于 `h_i` 的人。请你构造并返回输入队列所表示的实际队列。

## 输入格式

第一行输入 `n`。
接下来 `n` 行，每行 `h k`。

## 输出格式

输出 `n` 行，每行 `h k`，按重建后的队列顺序。

## 样例

**输入：**
```
6
7 0
4 4
7 1
5 0
6 1
5 2
```

**输出：**
```
5 0
7 0
5 2
6 1
4 4
7 1
```

## 数据范围

- 1 ≤ n ≤ 2000
