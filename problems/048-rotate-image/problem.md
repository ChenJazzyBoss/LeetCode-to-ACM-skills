# 48. 旋转图像

**难度**：Medium
**知识点**：数组、矩阵
**输入模式**：matrix

## 题目描述

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像，请你将图像顺时针旋转 90 度。你必须在原地旋转图像，但本题以输出旋转后的矩阵即可。

## 输入格式

第一行输入一个整数 `n`，表示矩阵大小。
接下来 `n` 行，每行 `n` 个整数，表示矩阵元素。

## 输出格式

输出旋转后的 `n × n` 矩阵，每行元素用空格分隔。

## 样例

**输入：**
```
3
1 2 3
4 5 6
7 8 9
```

**输出：**
```
7 4 1
8 5 2
9 6 3
```

## 数据范围

- n = matrix.length = matrix[i].length
- 1 ≤ n ≤ 20
- -1000 ≤ matrix[i][j] ≤ 1000
