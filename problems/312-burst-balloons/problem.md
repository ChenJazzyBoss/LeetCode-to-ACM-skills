# 312. 戳气球

**难度**：Hard
**知识点**：动态规划、数组
**输入模式**：basic

## 题目描述

有 `n` 个气球，编号为 `0` 到 `n-1`，每个气球上都标有一个数字，存在数组 `nums` 中。戳破第 `i` 个气球，你可以获得 `nums[left] * nums[i] * nums[right]` 枚硬币（`left` 和 `right` 是和 `i` 相邻的两个气球）。求能获得硬币的最大数量。气球两侧可视为各有一个值为 1 的虚拟气球。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出最大硬币数。

## 样例

**输入：**
```
4
3 1 5 8
```

**输出：**
```
167
```

## 数据范围

- 1 ≤ n ≤ 300
- 0 ≤ nums[i] ≤ 100
