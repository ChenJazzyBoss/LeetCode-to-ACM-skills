# 438. 找到字符串中所有字母异位词

**难度**：Medium
**知识点**：滑动窗口、哈希表、字符串
**输入模式**：basic

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的异位词的子串，返回这些子串的起始索引（空格分隔，若无输出空行）。异位词指由相同字母重排列形成的字符串（包括相同的字符串）。

## 输入格式

第一行输入字符串 `s`。
第二行输入字符串 `p`。

## 输出格式

输出所有起始索引，空格分隔。若无则输出空行。

## 样例

**输入：**
```
cbaebabacd
abc
```

**输出：**
```
0 6
```

## 数据范围

- 1 ≤ len(s), len(p) ≤ 3×10⁴
