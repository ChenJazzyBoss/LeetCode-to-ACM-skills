# 448. 找到所有数组中消失的数字

**难度**：Easy
**知识点**：数组、哈希表
**输入模式**：basic

## 题目描述

给你一个含 `n` 个整数的数组 `nums`，其中 `nums[i]` 在区间 `[1, n]` 内。请你找出所有在 `[1, n]` 范围内但没有出现在 `nums` 中的数字，并以升序输出。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出所有消失的数字，升序，空格分隔。若无则输出空行。

## 样例

**输入：**
```
4
4 3 2 7
```

**输出：**
```
1
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 1 ≤ nums[i] ≤ n
