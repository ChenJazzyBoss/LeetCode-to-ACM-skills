# 287. 寻找重复数

**难度**：Medium
**知识点**：双指针、数组、二分查找
**输入模式**：basic

## 题目描述

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 的范围内（含边界）。假设只有一个重复的整数，返回这个重复的数。要求不修改数组且只使用常量额外空间。

## 输入格式

第一行输入 `n+1`（数组长度）。
第二行输入 `n+1` 个整数。

## 输出格式

输出重复的数字。

## 样例

**输入：**
```
5
1 3 4 2 2
```

**输出：**
```
2
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- nums.length == n + 1
- 1 ≤ nums[i] ≤ n
