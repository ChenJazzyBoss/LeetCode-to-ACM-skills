# 739. 每日温度

**难度**：Medium
**知识点**：栈、数组、单调栈
**输入模式**：basic

## 题目描述

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，使得 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果此后没有更高的温度，则为 `0`。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。

## 输出格式

输出 `n` 个整数，空格分隔。

## 样例

**输入：**
```
8
73 74 75 71 69 72 76 73
```

**输出：**
```
1 1 4 2 1 1 0 0
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 30 ≤ temperatures[i] ≤ 100
