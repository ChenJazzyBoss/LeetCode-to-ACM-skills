# 538. 把二叉搜索树转换为累加树

**难度**：Medium
**知识点**：二叉树、DFS
**输入模式**：tree

## 题目描述

给出二叉搜索树的根节点，该树的节点值各不相同，请你将其转换为累加树，使每个节点的新值等于原树中大于或等于该节点值的所有节点值之和。输入为该 BST 的层序序列（`null` 表示空节点）。输出转换后树的层序序列（保留 `null` 占位）。

## 输入格式

第一行输入以空格分隔的层序序列，`null` 表示空节点。

## 输出格式

输出转换后的层序序列，空节点输出 `null`，空格分隔。

## 样例

**输入：**
```
4 1 6 0 2 5 7 null null null 3 null null null 8
```

**输出：**
```
30 36 21 36 35 26 15 null null null 33 null null null 8
```

## 数据范围

- 节点数 ≤ 100
