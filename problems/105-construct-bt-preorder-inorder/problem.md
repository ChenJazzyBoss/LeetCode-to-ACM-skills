# 105. 从前序与中序遍历序列构造二叉树

**难度**：Medium
**知识点**：二叉树、数组、DFS
**输入模式**：basic

## 题目描述

给定两个整数数组 `preorder` 和 `inorder`，其中 `preorder` 是二叉树的前序遍历，`inorder` 是同一棵树的中序遍历。请构造并返回这棵二叉树的后序遍历序列（用空格分隔）。

## 输入格式

第一行输入一个整数 `n`，表示节点数。
第二行输入 `n` 个整数，表示前序遍历。
第三行输入 `n` 个整数，表示中序遍历。

## 输出格式

输出该二叉树的后序遍历，节点值用空格分隔。

## 样例

**输入：**
```
3
3 9 20
9 3 20
```

**输出：**
```
9 20 3
```

## 数据范围

- 1 ≤ n ≤ 3000
- preorder 和 inorder 互不相同
