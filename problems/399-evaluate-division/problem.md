# 399. 除法求值

**难度**：Medium
**知识点**：图论、DFS、并查集
**输入模式**：graph

## 题目描述

给你一些变量对 `equations` 和对应结果 `values`，以及若干查询 `queries`。对于每个查询，若答案存在返回结果（保留 2 位小数），否则返回 `-1.00`。变量为不含空格的字符串。

## 输入格式

第一行输入 `m`，表示等式数。
接下来 `m` 行，每行 `a b v`，表示 `a / b = v`。
下一行输入 `q`，表示查询数。
接下来 `q` 行，每行 `a b`，查询 `a / b`。

## 输出格式

每行一个查询结果，保留 2 位小数。

## 样例

**输入：**
```
2
a b 2.0
b c 3.0
2
a c
b a
```

**输出：**
```
6.00
0.50
```

## 数据范围

- 1 ≤ m, q ≤ 20
- 变量为长度 1-5 的小写字母串
