# 139. 单词拆分

**难度**：Medium
**知识点**：动态规划、字符串、哈希表
**输入模式**：basic

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。请你判断是否可以利用字典中出现的单词拼接出 `s`。可以重复使用字典中的单词。输出 `True` 或 `False`。

## 输入格式

第一行输入一个字符串 `s`（不含空格）。
第二行输入一个整数 `m`，表示字典中的单词数。
接下来 `m` 行，每行一个单词。

## 输出格式

输出 `True` 或 `False`。

## 样例

**输入：**
```
leetcode
2
leet
code
```

**输出：**
```
True
```
