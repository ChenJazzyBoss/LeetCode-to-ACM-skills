# 1. 两数之和

**难度**：Easy
**知识点**：哈希表、数组
**输入模式**：basic

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出和为目标值 `target` 的那两个整数，并返回它们的数组下标（从 0 开始）。

你可以假设每种输入只会对应一个答案，并且不能使用同一个元素两次。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个整数，表示数组 `nums`。
第三行输入一个整数 `target`，表示目标值。

## 输出格式

输出两个整数，用空格分隔，表示两个数的下标（从小到大）。

## 样例

**输入：**
```
4
2 7 11 15
9
```

**输出：**
```
0 1
```

## 数据范围

- 2 ≤ n ≤ 10⁴
- -10⁹ ≤ nums[i] ≤ 10⁹
- -10⁹ ≤ target ≤ 10⁹
- 只存在一个有效答案
