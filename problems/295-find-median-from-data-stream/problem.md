# 295. 数据流的中位数

**难度**：Hard
**知识点**：堆、设计
**输入模式**：basic

## 题目描述

中位数是有序整数列表的中间数。请设计一个数据结构，支持 `ADDNUM num`（添加一个数到数据流）和 `FINDMEDIAN`（返回当前所有数据的中位数）。若数据数为偶数，返回中间两数的平均值（保留 1 位小数）。

## 输入格式

第一行输入操作数 `q`。
接下来 `q` 行，每行：
- `ADDNUM num`
- `FINDMEDIAN`

## 输出格式

按顺序输出每个 `FINDMEDIAN` 的结果，保留 1 位小数。

## 样例

**输入：**
```
5
ADDNUM 1
ADDNUM 2
FINDMEDIAN
ADDNUM 3
FINDMEDIAN
```

**输出：**
```
1.5
2.0
```

## 数据范围

- 1 ≤ q ≤ 5×10⁴
- -10⁵ ≤ num ≤ 10⁵
