# 155. 最小栈

**难度**：Medium
**知识点**：栈、设计
**输入模式**：basic

## 题目描述

设计一个支持 `push`、`pop`、`top` 操作，并能在常数时间内检索到最小元素的栈。

实现以下操作：
- `push x` — 将元素 x 推入栈中
- `pop` — 删除栈顶元素
- `top` — 获取栈顶元素
- `getMin` — 获取栈中的最小元素

## 输入格式

第一行输入一个整数 `q`，表示操作次数。
接下来 `q` 行，每行一个操作：
- `push x`
- `pop`
- `top`
- `getMin`

## 输出格式

对于每个 `top` 和 `getMin` 操作，输出对应的结果（每行一个）。

## 样例

**输入：**
```
7
push -2
push 0
push -3
getMin
pop
top
getMin
```

**输出：**
```
-3
0
-2
```

## 数据范围

- 1 ≤ q ≤ 10⁵
- -2³¹ ≤ x ≤ 2³¹ - 1
- pop、top 和 getMin 操作总是在非空栈上调用
