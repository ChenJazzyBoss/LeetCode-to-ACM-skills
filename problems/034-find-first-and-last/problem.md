# 34. 在排序数组中查找元素的第一个和最后一个位置

**难度**：Medium
**知识点**：二分查找、数组
**输入模式**：basic

## 题目描述

给定一个按照升序排列的整数数组 `nums` 和一个目标值 `target`，找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值，返回 `-1 -1`。

## 输入格式

第一行输入 `n` 个整数，表示升序数组。
第二行输入一个整数 `target`。

## 输出格式

输出两个整数，空格分隔，表示开始位置和结束位置。不存在则输出 `-1 -1`。

## 样例

**输入：**
```
5 7 7 8 8 10
8
```

**输出：**
```
3 4
```

## 数据范围

- 0 ≤ n ≤ 10⁵
- -10⁹ ≤ nums[i] ≤ 10⁹
- -10⁹ ≤ target ≤ 10⁹
