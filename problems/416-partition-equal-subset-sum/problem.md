# 416. 分割等和子集

**难度**：Medium
**知识点**：动态规划、数组
**输入模式**：basic

## 题目描述

给你一个只包含正整数的非空数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。输出 `True` 或 `False`。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个正整数。

## 输出格式

输出 `True` 或 `False`。

## 样例

**输入：**
```
4
1 5 11 5
```

**输出：**
```
True
```

## 数据范围

- 1 ≤ n ≤ 200
- 1 ≤ nums[i] ≤ 100
