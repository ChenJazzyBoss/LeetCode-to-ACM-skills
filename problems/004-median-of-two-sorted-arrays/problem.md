# 4. 寻找两个正序数组的中位数

**难度**：Hard
**知识点**：二分查找、数组
**输入模式**：basic

## 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`，找出并返回这两个正序数组的中位数。

## 输入格式

第一行输入 `m` 个整数，表示第一个有序数组。
第二行输入 `n` 个整数，表示第二个有序数组。

## 输出格式

输出中位数。如果合并后数组长度为偶数，输出下中位数（即第 (m+n)/2 个元素的值）。

## 样例

**输入：**
```
1 3
2
```

**输出：**
```
2
```

## 数据范围

- 0 ≤ m, n ≤ 1000
- -10⁶ ≤ nums[i] ≤ 10⁶
