# 141. 环形链表

**难度**：Easy
**知识点**：链表、双指针、哈希表
**输入模式**：basic

## 题目描述

给你一个链表的头节点，判断链表中是否有环。本题以整数序列描述链表：第 1 个数为头节点值，按顺序构成链表；额外给出一个 `pos` 表示尾节点连接到的节点下标（从 0 开始，`-1` 表示无环）。输出 `True` 或 `False`。

## 输入格式

第一行输入若干个整数，空格分隔，表示链表节点值（按顺序）。
第二行输入一个整数 `pos`，表示尾节点连接到的节点下标（`-1` 表示无环）。

## 输出格式

输出 `True` 或 `False`。

## 样例

**输入：**
```
3 2 0 -4
1
```

**输出：**
```
True
```

## 数据范围

- 0 ≤ 节点数 ≤ 10⁴
- -10⁵ ≤ Node.val ≤ 10⁵
- -1 ≤ pos < 节点数
