# 253. 会议室 II

**难度**：Medium
**知识点**：排序、堆、贪心算法
**输入模式**：matrix

## 题目描述

给你一个会议时间安排的数组 `intervals`，每个会议包含开始时间和结束时间 `[[s1,e1],[s2,e2],...]`，返回所需的最少会议室数量。

## 输入格式

第一行输入一个整数 `m`，表示会议数。
接下来 `m` 行，每行输入两个整数 `s e`，表示会议开始与结束时间。

## 输出格式

输出最少会议室数。

## 样例

**输入：**
```
3
0 30
5 10
15 20
```

**输出：**
```
2
```

## 数据范围

- 1 ≤ m ≤ 10⁴
- 0 ≤ s < e ≤ 10⁶
