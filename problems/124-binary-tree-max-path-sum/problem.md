# 124. 二叉树中的最大路径和

**难度**：Hard
**知识点**：二叉树、DFS、动态规划
**输入模式**：tree

## 题目描述

二叉树中的「路径」被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。该路径至少包含一个节点，且不一定经过根节点。路径和是路径中各节点值的总和。给你一棵以编号 1 为根的二叉树（节点带权值），求其最大路径和。输入第一行为节点权值列表（按编号 1..n 顺序），随后 n-1 行描述父子边（每行 `p c L/R` 表示 c 是 p 的左/右孩子）。

## 输入格式

第一行输入 `n` 个整数，为节点 1..n 的权值。
接下来 `n-1` 行，每行输入 `p c side`，`side` 为 `L`（左）或 `R`（右）。

## 输出格式

输出一个整数，表示最大路径和。

## 样例

**输入：**
```
1 2 3
1 2 L
1 3 R
```

**输出：**
```
6
```

## 数据范围

- 1 ≤ n ≤ 3×10⁴
- -1000 ≤ val ≤ 1000
