# 338. 比特位计数

**难度**：Easy
**知识点**：位运算、动态规划
**输入模式**：basic

## 题目描述

给定一个非负整数 `n`，对于 `0 ≤ i ≤ n` 的每个 `i`，计算其二进制表示中 `1` 的个数，返回一个长度为 `n + 1` 的数组。

## 输入格式

输入一个非负整数 `n`。

## 输出格式

输出 `n + 1` 个整数，空格分隔，第 `i` 个数表示 `i` 的二进制中 `1` 的个数。

## 样例

**输入：**
```
5
```

**输出：**
```
0 1 1 2 1 2
```

## 数据范围

- 0 ≤ n ≤ 10⁵
