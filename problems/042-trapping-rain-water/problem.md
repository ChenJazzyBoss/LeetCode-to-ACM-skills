# 42. 接雨水

**难度**：Hard
**知识点**：双指针、栈、动态规划
**输入模式**：basic

## 题目描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 输入格式

第一行输入一个整数 `n`，表示柱子数量。
第二行输入 `n` 个非负整数，表示每根柱子的高度。

## 输出格式

输出一个整数，表示能接住的雨水量。

## 样例

**输入：**
```
12
0 1 0 2 1 0 1 3 2 1 2 1
```

**输出：**
```
6
```

## 数据范围

- n ≥ 1
- 0 ≤ height[i] ≤ 10⁵
