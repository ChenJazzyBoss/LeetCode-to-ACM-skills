# 560. 和为 K 的子数组

**难度**：Medium
**知识点**：前缀和、哈希表、数组
**输入模式**：basic

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的连续子数组的个数。

## 输入格式

第一行输入 `n`。
第二行输入 `n` 个整数。
第三行输入 `k`。

## 输出格式

输出子数组个数。

## 样例

**输入：**
```
3
1 1 1
2
```

**输出：**
```
2
```

## 数据范围

- 1 ≤ n ≤ 2×10⁴
- -1000 ≤ nums[i] ≤ 1000
- -10⁷ ≤ k ≤ 10⁷
