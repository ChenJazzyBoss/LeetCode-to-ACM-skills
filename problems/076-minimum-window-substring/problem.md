# 76. 最小覆盖子串

**难度**：Hard
**知识点**：滑动窗口、哈希表、字符串
**输入模式**：basic

## 题目描述

给定字符串 `s` 和 `t`，返回 `s` 中涵盖 `t` 所有字符（包括重复字符）的最小子串。如果不存在这样的子串，返回空字符串。

## 输入格式

第一行输入字符串 `s`。
第二行输入字符串 `t`。

## 输出格式

输出最小覆盖子串。如果有多个满足条件的子串长度相同，返回最左边的那个。如果不存在，输出空行。

## 样例

**输入：**
```
ADOBECODEBANC
ABC
```

**输出：**
```
BANC
```

## 数据范围

- 1 ≤ |s|, |t| ≤ 10⁵
- s 和 t 由英文字母组成
