# 23. 合并 K 个升序链表

**难度**：Hard
**知识点**：链表、堆、分治算法
**输入模式**：basic

## 题目描述

给定一个链表数组，每个链表都已经按升序排列。请将所有链表合并到一个升序链表中，返回合并后的链表。

## 输入格式

第一行输入一个整数 `k`，表示链表数量。
接下来 `k` 行，每行输入一个升序整数序列（空格分隔），表示一个链表。空链表用空行表示。

## 输出格式

输出合并后的升序序列，空格分隔。

## 样例

**输入：**
```
3
1 4 5
1 3 4
2 6
```

**输出：**
```
1 1 2 3 4 4 5 6
```

## 数据范围

- 0 ≤ k ≤ 10⁴
- 每个链表长度 ≤ 500
- -10⁴ ≤ val ≤ 10⁴
