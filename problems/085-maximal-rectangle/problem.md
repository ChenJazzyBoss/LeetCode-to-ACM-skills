# 85. 最大矩形

**难度**：Hard
**知识点**：栈、动态规划、矩阵
**输入模式**：matrix

## 题目描述

给定一个仅包含 `0` 和 `1` 的二维二进制矩阵 `matrix`，找出只包含 `1` 的最大矩形，并返回其面积。

## 输入格式

第一行输入两个整数 `rows` 和 `cols`。
接下来 `rows` 行，每行输入 `cols` 个字符（`0` 或 `1`），字符之间无空格。

## 输出格式

输出一个整数，表示最大矩形面积。

## 样例

**输入：**
```
4 5
10100
10111
11111
10010
```

**输出：**
```
6
```

## 数据范围

- 1 ≤ rows, cols ≤ 200
- matrix[i][j] ∈ {'0', '1'}
