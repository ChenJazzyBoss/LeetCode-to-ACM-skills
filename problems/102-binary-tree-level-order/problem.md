# 102. 二叉树的层序遍历

**难度**：Medium
**知识点**：二叉树、BFS
**输入模式**：tree

## 题目描述

给定一棵二叉树，返回其节点值的层序遍历结果（逐层地，从左到右）。

## 输入格式

第一行输入一个整数 `n`，表示节点数。
接下来 `n-1` 行，每行两个整数 `u v`，表示一条边（u 是 v 的父节点）。
根节点为 1。

## 输出格式

输出层序遍历结果，每层占一行，节点编号用空格分隔。

## 样例

**输入：**
```
3
1 2
1 3
```

**输出：**
```
1
2 3
```

## 数据范围

- 0 ≤ n ≤ 2000
