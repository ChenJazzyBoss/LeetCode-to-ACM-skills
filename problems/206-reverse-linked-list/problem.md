# 206. 反转链表

**难度**：Easy
**知识点**：链表、递归
**输入模式**：basic

## 题目描述

给你单链表的头节点，请你反转链表，并返回反转后的链表。

本题以数组形式输入链表：第一行输入数组长度 `n`，第二行输入 `n` 个整数表示链表各节点的值（按链表顺序）。输出反转后链表的值序列。

## 输入格式

第一行输入一个整数 `n`，表示链表节点数。
第二行输入 `n` 个整数，表示链表各节点的值。

## 输出格式

输出 `n` 个整数（空格分隔），表示反转后链表的值序列。

## 样例

**输入：**
```
5
1 2 3 4 5
```

**输出：**
```
5 4 3 2 1
```

## 数据范围

- 0 ≤ n ≤ 5000
- -5000 ≤ Node.val ≤ 5000
