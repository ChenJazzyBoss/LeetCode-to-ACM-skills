# 142. 环形链表 II

**难度**：Medium
**知识点**：链表、双指针、哈希表
**输入模式**：basic

## 题目描述

给定一个链表，返回链表开始入环的第一个节点下标（从 0 开始）。如果链表无环，返回 `-1`。输入方式同 141 题：节点值序列 + `pos`（尾节点连接到的下标，`-1` 表示无环）。

## 输入格式

第一行输入若干整数，空格分隔，表示链表节点值。
第二行输入一个整数 `pos`。

## 输出格式

输出入环节点的下标，无环输出 `-1`。

## 样例

**输入：**
```
3 2 0 -4
1
```

**输出：**
```
1
```

## 数据范围

- 0 ≤ 节点数 ≤ 10⁴
- -1 ≤ pos < 节点数
