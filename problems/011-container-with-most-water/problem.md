# 11. 盛最多水的容器

**难度**：Medium
**知识点**：双指针、贪心算法
**输入模式**：basic

## 题目描述

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个非负整数，表示高度数组。

## 输出格式

输出一个整数，表示最大水量。

## 样例

**输入：**
```
9
1 8 6 2 5 4 8 3 7
```

**输出：**
```
49
```

## 数据范围

- 2 ≤ n ≤ 10⁵
- 0 ≤ height[i] ≤ 10⁴
