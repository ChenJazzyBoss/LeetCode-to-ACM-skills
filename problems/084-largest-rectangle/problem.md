# 84. 柱状图中最大的矩形

**难度**：Hard
**知识点**：栈、数组、单调栈
**输入模式**：basic

## 题目描述

给定一个整数数组 `heights`，表示柱状图中各个柱子的高度。每个柱子宽度为 1，求在该柱状图中能勾勒出的最大矩形面积。

## 输入格式

第一行输入一个整数 `n`，表示柱子数量。
第二行输入 `n` 个非负整数，表示柱子高度。

## 输出格式

输出一个整数，表示最大矩形面积。

## 样例

**输入：**
```
6
2 1 5 6 2 3
```

**输出：**
```
10
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 0 ≤ heights[i] ≤ 10⁴
