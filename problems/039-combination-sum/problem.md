# 39. 组合总和

**难度**：Medium
**知识点**：回溯算法、数组
**输入模式**：basic

## 题目描述

给定一个无重复元素的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为 `target` 的所有唯一组合。`candidates` 中的同一个数字可以无限制重复被选取。

## 输入格式

第一行输入一个整数 `n`，表示数组长度。
第二行输入 `n` 个正整数，表示候选数组。
第三行输入一个整数 `target`。

## 输出格式

输出所有组合，每个组合占一行，数字用空格分隔，组合内数字按非递减顺序排列。所有组合按字典序输出。

## 样例

**输入：**
```
3
2 3 6 7
7
```

**输出：**
```
2 2 3
7
```

## 数据范围

- 1 ≤ n ≤ 30
- 1 ≤ candidates[i] ≤ 200
- 1 ≤ target ≤ 500
