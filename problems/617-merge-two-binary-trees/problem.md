# 617. 合并二叉树

**难度**：Easy
**知识点**：二叉树、DFS、BFS
**输入模式**：tree

## 题目描述

给你两棵二叉树 `root1` 和 `root2`。你需要将这两棵树合并。合并规则是：如果两个节点重叠，则将两个节点的值相加作为合并后节点的新值；否则不为 `null` 的节点将直接作为新二叉树的节点。输入两行层序序列，输出合并后树的层序序列（用空格分隔，跳过空节点）。

## 输入格式

第一行输入 `root1` 的层序序列。
第二行输入 `root2` 的层序序列。
`null` 表示空节点。

## 输出格式

输出合并后树的层序遍历（不含空节点），空格分隔。

## 样例

**输入：**
```
1 3 2 5
2 1 3 null 4 null 7
```

**输出：**
```
3 4 5 5 4 null 7
```

## 数据范围

- 节点数 ≤ 2000
