# 79. 单词搜索

**难度**：Medium
**知识点**：回溯算法、矩阵
**输入模式**：matrix

## 题目描述

给定一个 `m × n` 的二维字符网格 `board` 和一个字符串 `word`，如果 `word` 存在于网格中，返回 `true`；否则返回 `false`。单词必须按照字母顺序通过相邻的单元格内的字母构成，其中"相邻"单元格是水平或垂直相邻的。同一个单元格内的字母不允许被重复使用。

## 输入格式

第一行输入两个整数 `m` 和 `n`，表示网格行数和列数。
接下来 `m` 行，每行 `n` 个字符（空格分隔），表示网格。
最后一行输入目标字符串 `word`。

## 输出格式

输出 `true` 或 `false`。

## 样例

**输入：**
```
3 4
A B C E
S F C S
A D E E
ABCCED
```

**输出：**
```
true
```

## 数据范围

- 1 ≤ m, n ≤ 6
- 1 ≤ |word| ≤ 15
- board 和 word 仅由大小写英文字母组成
