# 121. 买卖股票的最佳时机

**难度**：Easy
**知识点**：动态规划、数组
**输入模式**：basic

## 题目描述

给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。你只能选择某一天买入并在未来的某一天卖出，设计一个算法来计算你所能获取的最大利润。如果不能获取利润，返回 0。

## 输入格式

第一行输入一个整数 `n`，表示天数。
第二行输入 `n` 个整数，表示每天的股票价格。

## 输出格式

输出一个整数，表示最大利润（无利润则输出 0）。

## 样例

**输入：**
```
6
7 1 5 3 6 4
```

**输出：**
```
5
```

## 数据范围

- 1 ≤ n ≤ 10⁵
- 0 ≤ prices[i] ≤ 10⁴
