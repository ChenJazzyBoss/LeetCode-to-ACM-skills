# 148. 排序链表

**难度**：Medium
**知识点**：链表、排序、分治算法
**输入模式**：basic

## 题目描述

给你链表的头节点，请将其按升序排列并返回。本题以整数序列输入表示链表节点值（按顺序），输出排序后的节点值序列（空格分隔）。

## 输入格式

第一行输入一个整数 `n`，表示节点数。
第二行输入 `n` 个整数，空格分隔。

## 输出格式

输出排序后的 `n` 个整数，空格分隔。

## 样例

**输入：**
```
4
4 2 1 3
```

**输出：**
```
1 2 3 4
```

## 数据范围

- 0 ≤ n ≤ 5×10⁴
- -10⁵ ≤ Node.val ≤ 10⁵
