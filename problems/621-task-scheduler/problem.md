# 621. 任务调度器

**难度**：Medium
**知识点**：贪心算法、堆、数组
**输入模式**：basic

## 题目描述

给你一个用字符数组 `tasks` 表示的 CPU 需要执行的任务列表，用字母 `A`-`Z` 表示。每个字母表示一种不同种类的任务，可以按任意顺序执行。每个 CPU 周期可以执行一个任务，或者在待命状态。两个相同种类任务之间必须有长度为 `n` 的冷却时间。计算完成所有任务所需的最少周期数。

## 输入格式

第一行输入任务列表（连续的字母字符串，或空格分隔的字母）。
第二行输入冷却时间 `n`。

## 输出格式

输出最少周期数。

## 样例

**输入：**
```
AAABBB
2
```

**输出：**
```
8
```

## 数据范围

- 1 ≤ tasks.length ≤ 10⁴
- 0 ≤ n ≤ 100
