# 301. 删除无效的括号

**难度**：Hard
**知识点**：BFS、回溯算法、字符串
**输入模式**：basic

## 题目描述

给你一个由若干括号和字母组成的字符串 `s`，删除最少数量的无效括号，使得输入的字符串有效。返回所有可能的结果（按字典序升序输出，每个结果一行）。当有多种方案时，输出其中删除数量最少且合法的全部去重结果。

## 输入格式

第一行输入字符串 `s`。

## 输出格式

每行一个合法结果（已删除最少括号）。按字典序升序。

## 样例

**输入：**
```
()())()
```

**输出：**
```
(())()
()()()
```

## 数据范围

- 1 ≤ len(s) ≤ 25
