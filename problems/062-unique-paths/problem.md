# 62. 不同路径

**难度**：Medium
**知识点**：动态规划、组合数学
**输入模式**：basic

## 题目描述

一个机器人位于一个 `m × n` 网格的左上角。机器人每次只能向下或向右移动一步。机器人试图到达网格的右下角。问总共有多少条不同的路径？

## 输入格式

输入两个整数 `m` 和 `n`，空格分隔，表示网格的行数和列数。

## 输出格式

输出一个整数，表示不同的路径数量。

## 样例

**输入：**
```
3 7
```

**输出：**
```
28
```

## 数据范围

- 1 ≤ m, n ≤ 100
- 题目数据保证答案小于等于 2 × 10⁹
