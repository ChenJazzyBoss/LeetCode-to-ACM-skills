## §1 需求描述 ⭐强烈建议提供

构建一个 Claude Code Skill（acm），帮助用户从 LeetCode 格式过渡到 ACM 竞赛格式。大模型扮演三种角色：

1. **出题官** — 从内置题库出题，将 LeetCode 题目转为 ACM 格式题面
2. **裁判** — 运行用户提交的代码，逐用例对比，判定 AC/WA/RE/TLE/CE，打分
3. **教练** — 分析错误原因，给出修复建议，记录薄弱点

核心特点：
- Hot 100 题目（100道）全部内置，离线可用
- 其他题目用户提出时再在线抓取
- 支持随机测验（1/3/5 题），聊天式交互让用户选择
- 交互方式以 Skill（自然语言）为主，评判引擎用可执行脚本确保确定性

---

## §2 命令结构 ⭐建议提供

所有命令通过 `/acm` Skill 触发，交互方式为聊天式问答：

| 命令 | 描述 |
|------|------|
| `/acm teach` | 教学：ACM 输入输出格式速成 |
| `/acm fetch <题号>` | 从内置题库获取题目（命中直接返回），未命中则在线抓取 |
| `/acm quiz` | 随机测验：弹出选择（1题快速练手/3题小测验/5题模拟赛），可选指定知识点 |
| `/acm practice <题号>` | 出一道 ACM 题让用户练，生成测试用例 |
| `/acm judge` | 评判用户提交的代码 |
| `/acm hint` | 对当前题目给出提示 |
| `/acm review` | 分析错误，给出修复建议 |

## §3 参数与选项（选填）

| 选项 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `<题号>` | int | 无 | 力扣题号 |
| `--tag` | string | 全部 | 知识点筛选（DP/二叉树/图论/哈希/双指针/...） |
| `--count` | int | 1 | 随机测验题目数量（1/3/5） |
